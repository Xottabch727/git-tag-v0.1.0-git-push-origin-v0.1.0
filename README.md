# ACC Marshal

Программа для маршалов и стюардов гоночного сервера **Assetto Corsa Competizione**.
Работает на ПК маршала рядом с игрой и берёт на себя рутину:

- **Штрафы.** Выбираете пилота и решение, программа готовит команду для чата сервера и сама кладёт её в буфер обмена. Маршалу остаётся переключиться в игру и вставить.
- **Журнал решений.** Кто, за что и какое наказание получил. Всё сохраняется между запусками.
- **Стартовая решётка.** Берёт результаты квалификации с сервера, применяет штрафы из журнала (откат на N мест, пит-лейн), реверс топ-N и правило 107%, заливает `entrylist.json` на сервер с резервной копией.
- **Итоги гонки.** Пересчитывает классификацию с послегоночными штрафами (секунды, дисквалификация).
- **Объявления.** Готовые тексты для VSC, SC, флагов и решений стюардов, с транслитом на случай, если чат игры не показывает кириллицу.
- **Подключение к серверу** через папку на ПК, FTP, FTPS или SFTP (для хостингов).

## Установка

**Windows, без Python:** откройте раздел [Releases](../../releases), скачайте `ACC-Marshal.exe` и запустите.

**Из исходников:** нужен Python 3.9+ (с tkinter, на Windows он ставится вместе с Python).

```
python run.py
```

Для SFTP дополнительно: `pip install paramiko`.

## Быстрый старт

1. Вкладка **Подключение**: укажите, где лежит сервер.
   - Для хостинга выберите FTP / FTPS / SFTP, введите адрес, логин и пароль из панели хостинга.
   - Поле «Папка сервера на хостинге» — путь, где лежат папки `cfg` и `results` (например `/server`).
2. Нажмите **Подключиться**. Программа найдёт файлы квалификаций и гонок и существующий `entrylist.json`.
3. Вкладка **Штрафы**: введите номер машины, выберите решение, нажмите **Добавить** (Ctrl+Enter). Команда уже в буфере, вставьте её в чат игры.
4. Вкладка **Решётка**: проверьте итоговый порядок и нажмите **Залить на сервер**. Затем перезапустите сервер через панель хостинга.
5. После гонки вкладка **Итоги гонки** покажет классификацию с послегоночными штрафами.

## Как программа определяет пилотов

В `entrylist.json` запись ищется по **Steam ID пилота** (`playerID`), а если не нашлась, то по номеру машины. Поэтому позиции проставляются корректно даже при `raceNumber: -1`. Записи, которых не было в квалификации, остаются без изменений.

## Важно знать

- **Названия команд проверьте по мануалу вашего сервера** (папка документов ACC). По умолчанию используются `/tp5`, `/tp15`, `/dt`, `/dq`, `/clear`. Если у вас иначе, поправьте раздел `commands` в `~/.acc_marshal/config.json`.
- **Решётка читается только при запуске сервера.** После заливки `entrylist.json` перезапустите сервер целиком. Как сервер сочетает `defaultGridPosition` с квалификацией в одном расписании, проверьте на тестовой гонке: безопасная схема — квалификация в одном запуске, гонка без квалификации в следующем.
- Некоторые хостинги **перезаписывают** `entrylist.json` из своего редактора конфигов. Проверьте это на тесте.
- Штрафы, выданные командами во время гонки, сервер уже учёл в результатах. Во вкладке «Итоги гонки» добавляются только решения «к итогам гонки» и «дисквалификация по итогам».
- SC и VSC в ACC не являются функциями игры. Это регламент вашей лиги, а программа только готовит объявления.
- Пароль от хостинга по умолчанию **не сохраняется**. Если включить «Запомнить пароль», он лежит в открытом виде в `~/.acc_marshal/config.json`.
- SFTP не проверялся на живом сервере. FTP проверен на тестовом эмуляторе.

## Файлы программы

Всё хранится в папке `~/.acc_marshal` (на Windows `C:\Users\<имя>\.acc_marshal`):
`config.json` (настройки, шаблоны команд и объявлений), `log.json` (журнал решений), `log_*.json` (архивы после «Новый уикенд»).

## Разработка

```
python -m unittest discover -s tests -v
```

Структура: `acc_marshal/core.py` (решётка, итоги), `commands.py` (команды и объявления), `remote.py` (локально, FTP, SFTP), `storage.py` (настройки и журнал), `gui.py` (окно).

### Публикация релиза с .exe

1. Создайте репозиторий на GitHub и загрузите проект.
2. Создайте тег: `git tag v0.1.0 && git push origin v0.1.0`.
3. GitHub Actions соберёт `ACC-Marshal.exe` и приложит его к релизу. Ссылка на скачивание появится в разделе Releases.
